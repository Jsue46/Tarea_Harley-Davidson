# Stakeholders Finales del Negocio - Harley-Davidson SiL'K

## Version final

Esta es la version final para trabajar el **negocio** del caso Harley-Davidson SiL'K.

Se deja unicamente la clasificacion en:

1. **Stakeholders directos**
2. **Stakeholders indirectos**

## Criterio aplicado

- Se usan **roles del negocio**, no personas individuales.
- Si varias personas comparten el mismo rol o interes, se representan como un solo stakeholder.
- Los **directos** son los que interactuan con el negocio.
- Los **indirectos** son los que influyen, supervisan o reciben impacto, pero no operan directamente el negocio.

## Stakeholders directos

1. **Organizacion de Compras**
2. **Proveedores / Suministradores**
3. **Solicitantes internos de compra**
4. **Cuentas de Acreedores Comerciales**
5. **Logistica**
6. **Ingenieria / Desarrollo de Producto**
7. **Fabricacion / Centros de produccion**

## Stakeholders indirectos

1. **Alta Direccion / Consejo de Direccion y Estrategia**
2. **Grupo de Unidad de Compras (PUG)**
3. **Recursos Humanos**
4. **Consejo Asesor de Suministradores**

## Nota de uso

Para la **primera descomposicion del core del negocio**, se usan **solo los stakeholders directos**.
