# Software Architecture and Enterprise Quality Drivers Specification

Academic project developed for the **Systems Analysis and Design** course at the Universidad de San Carlos de Guatemala (First Semester 2026).

This repository contains an architectural case study analyzing enterprise software selection, architectural quality attributes (ISO/IEC 25010), deployment modeling, and stakeholder traceability matrices applied to an industrial scenario (Harley-Davidson SILK case).

---

## Overview

The study evaluates architectural tactics, deployment trade-offs, and quality drivers (scalability, availability, security, maintainability) to guide enterprise software selection and component partitioning in complex distributed environments.

---

## Contents and Artifacts

- **Quality Drivers & Constraints:** Comprehensive analysis of architectural drivers, business constraints, and non-functional requirements.
- **Architectural Deployment Diagrams:** UML deployment modeling mapping components to computational nodes and network tiers.
- **Traceability Matrices:** Detailed mapping connecting business criteria, use cases, and technical architectural tactics.
- **Enterprise Software Selection:** Comparative evaluation methodology for selecting enterprise software suites.
